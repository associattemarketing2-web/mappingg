# Mappingg SEO audit — executive summary (20 Oct 2026)

**Scope.** Every URL the site exposes was crawled twice with the same tool: the live site before any change (`2026-10-20-baseline-live-final`) and a production build of the fixed code served locally (`2026-10-20-after-local-final`, this folder). 1,761 URLs were discovered (sitemap, all static routes in `app/`, and every internal link) and **all 1,761 were fetched and checked** — none skipped. All 968 public pins (965 projects) and all 22 blog posts were also audited from the database, read-only.

**Overall.** The technical base was already solid: valid sitemap and robots.txt, a canonical on every page, structured data on every template, no server errors. The real problems were:

1. **False 404s** — DB read errors were treated as "not found", so valid pages could 404 and listings or the sitemap could be cached empty. Seen live on `/blog?page=2`. *Fixed.*
2. **Locality pages 404 after new data** — `/locations/wanowri` was linked but 404 because locality pages were only built at deploy time. *Fixed.*
3. **Half the projects had no city hub, and titles said "Pune & MMR"** — Bengaluru has 491 of 965 projects; `/cities/bengaluru` was linked from the blog but 404'd. *Fixed: hubs for Bengaluru, Delhi NCR and Hyderabad; titles show real coverage.*
4. **Project titles were generic and too long** — 926 titles over ~70 characters, all ending "Price, Location & Details" even with no price. 808 RERA numbers were never shown, and 466 names were in ALL CAPS. *Fixed: facts-only titles, RERA shown and in schema, title-case display, no URL changes.*
5. **Thin pages** — 640 indexable pages under 150 words. *Down to 49*, using overviews built only from each project's or developer's own data.
6. **FAQ schema bug** — every answer on `/faq` repeated the question. *Fixed.*

**Not yet done.** Nothing is deployed or committed. Search Console data is unavailable (API disabled), so there are no rankings, clicks or index status in this report, and Core Web Vitals were not measured (PageSpeed quota exhausted). Remaining items are data decisions: 8 same-name project pairs, a duplicate pin number (116), and missing price, area and description data for most registry-imported projects. See `REMAINING-ACTIONS.md`.
